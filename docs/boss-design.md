# boss 设计与验证边界

更新：2026-09-12。[中文首页](../README.md) · [技能入口](../skills/boss/SKILL.md)

## 目标

面向 Astra 额度消耗过快的使用痛点，让当前会话模型保留需求理解、方向判断和验收，将关键决策已定、边界清晰且有交接收益的重复批次、常规实现或功能检查交给 Worker。减少不必要的 Boss 执行与重复上下文，不查询价格、不估算费用、不承诺未经实测的额度节省。

Astra + Luna 是推荐展示的示例组合，Boss 不强制绑定 Astra。模型和 effort 必须一起可见：设置透明有助于理解分工，但显示 effort 不等于测量消耗速度。

## 调度与设置

- Boss 默认直接执行，承担深度理解、开放式设计、复杂推理及高难度实现。指定 Worker 不等于要求委派；任务名称或接口明确也不等于任务简单。
- Worker 可执行规则已定、边界明确、可独立验证的重复批次、常规实现或功能检查，不要求必须重复或涉及大量文件；工作量须足以抵消启动、交接、验收和预期修复的开销。关键设计或接口确定后重新判断一次，不因最初由 Boss 设计就默认全程直接执行。优先使用已有确定性工具，不为委派编造额外步骤。
- 每个完整工作包默认一个 Worker，一次发送任务包，一次返回汇总；不要求规划确认、逐项审批或常规中间汇报。真正阻塞时才提前联系，独立异常集中报告。
- Worker 模型与 effort 独立保持，分别支持固定与自动模式。自动 effort 优先采用兼容配置默认值，再按任务选择支持的强度。
- 新设置用于后续任务。旧 Worker 默认完成已有任务，不接收设置不匹配的新工作；需要立即切换时停止并核对已完成部分。
- 显式模型或 effort 不可用时报告具体冲突，不静默替换。未知内部配置和缺少后端回执不构成例行阻塞。
- 首次选择或相关变化时验证；普通任务复用结果。相同模型、effort 且无并发冲突的 Worker 可执行符合条件的相关工作包。
- 仅独立工作包可使用至多两个 Worker 并行，遵守宿主限额；共享可变资源串行。优先事件等待，不频繁检查中间文件或发送指导。
- Boss 集中验收原始标准，小范围残余缺陷直接修复；只有工作包内规则明确且可独立一次完成的修正才回交 Worker。若发现设计或理解难点，Boss 接管，不进入反复教学与返工循环。
- 会话上下文保存选择；仅在需要跨重启恢复且宿主支持加载时使用文件检查点。

## 身份与 effort 的证据

首先采用宿主直接提供的当前 turn 设置。没有时，Codex 辅助脚本使用 session ID 定位匹配文件名，流式读取目标文件的 `session_meta` 与 `turn_context`，不读取其他会话正文。

最新完整的 `turn_context` 决定模型与 effort；缺失字段保持 `null`，不从旧 turn 拼接。脚本输出 JSON，包括身份、设置、turn ID、时间、来源、scope 和简短诊断。尾部未完成记录可跳过；身份不符不返回该文件的模型设置。

默认标为“最近记录”，与可信当前 turn ID 匹配才标为当前 turn。两者都是宿主记录，不是后端模型路由证明。无 Node、无记录、无权限或格式变化时展示 unknown，继续正常委派。Worker 展示明确为已选择或已运行，不把调用参数当后端回执。

## 验证

脚本自动化测试覆盖匹配会话、最新多轮记录、字段缺失、记录未写完、读取失败、身份不符、参数优先级、歧义路径和不读取无关文件。打包测试覆盖副本漂移、过期文件移除与符号链接拒绝。

指令场景审查（静态规则核对，不是端到端结果）：

| 场景 | 预期行为 |
| --- | --- |
| 从零设计鹈鹕 SVG 动画 | Boss 直接执行，不先委派再纠偏 |
| 按已批准规则修改大量文件 | 单个 Worker 批量执行并一次汇总 |
| 网页设计及 DOM 接口已确定，存在独立常规功能模块 | 重新判断一次，可委派实现；不强制委派 |
| 按已有验收标准编写并执行功能测试 | 工作量足够且边界独立时可委派；Boss 保留视觉与最终验收 |
| 只需运行已有测试命令 | 直接调用工具，不为此创建 Worker |
| 修改一个明确字段 | 直接使用工具，不创建 Worker |
| 批量过程中部分输入不符合规则 | 完成独立项，汇总异常，不逐项问答 |
| 修复需要反复解释或重新设计 | Boss 接管相关部分，停止教学循环 |
| 固定 Luna + medium | 展示并保持两个设置，后续调用匹配 |
| 模型固定、effort 自动 | 保持模型，采用兼容默认或合适强度 |
| 只切换 effort | 更新选择版本，不向旧设置实例追加工作 |
| 切换模型后固定 effort 不兼容 | 报告具体冲突，不悄悄修改 effort |
| Boss 身份未知、脚本不可用 | 展示 unknown，继续可用的委派 |
| 仅有最近记录 | 保留来源限定，不冒充当前设置 |
| 其他 harness | 标为待适配，不臆造工具接口 |

自动化检查与静态场景审查不等于 Codex 多轮委派端到端实测，也不证明额度节省。后续以真实任务验证体验和质量，不引入自动价格查询或费用估算。
